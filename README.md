# UI Automation Project: Travel Assistant

Набор UI-автотестов для проверки чат-ассистента «Кэп» на сайте tutu.ru.  
Проект реализован на Python с использованием Selenium, Pytest, Allure, Jenkins и Selenoid.

## Цель проекта

Цель проекта — автоматизировать проверку ключевых сценариев работы чат-ассистента и организовать стабильный запуск тестов в локальной среде и в CI/CD через Jenkins.

---

## Что тестируется

В проекте проверяется работа чат-интерфейса, который встроен в страницу tutu.ru и открывается внутри `iframe`.  
Автотесты покрывают следующие пользовательские сценарии:

- открытие чата;
- проверку основных элементов интерфейса;
- отправку текстового сообщения;
- запуск голосового ввода;
- прикрепление файла;
- использование быстрых подсказок;
- ответы ассистента на подсказки;
- негативные сценарии работы формы.

## Особенности реализации

В проекте использован паттерн **Page Object Model**, что позволило вынести логику взаимодействия со страницей в отдельные классы и сделать тесты более читаемыми.

Дополнительно реализовано:

- разделение тестов по бизнес-логике продукта;
- параметризация тестов для проверки быстрых подсказок;
- явные ожидания для динамических элементов;
- работа с `iframe`;
- подготовка вложений для Allure-отчёта;
- поддержка локального и удалённого запуска;
- автоматическая отправка уведомлений о результате выполнения тестов в Telegram.

## Решённые технические задачи

В ходе работы над проектом были решены следующие задачи:

- стабилизация тестов с использованием явных ожиданий;

## Запуск локально

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск тестов
```bash
pytest
```

### Запуск с генерацией данных для Allure
```bash
pytest --alluredir=allure-results
```

## Запуск через Jenkins / Selenoid
Проект поддерживает запуск в Jenkins с использованием Selenoid.

Пример команды запуска:

```bash
pytest -s \
  --base-url="https://www.tutu.ru/" \
  --remote-url="https://selenoid.qa.guru/wd/hub" \
  --browser="chrome" \
  --browser-version="148.0" \
  --headless "false" \
  --remote true \
  --window-size="1920x1080" \
  --alluredir=allure-results
```

Сборка автоматически выполняет:

* клонирование репозитория;
* установку зависимостей;
* запуск тестов;
* генерацию Allure-отчёта;
* отправку результата в Telegram.

## Allure report
После выполнения тестов можно сгенерировать отчёт:

```bash
allure generate allure-results -o allure-report --clean
allure open allure-report
```
В отчёте доступны:
* скриншоты;
* HTML страницы;
* логи браузера;
* видео прохождения тестов;
* подробные шаги выполнения через allure.step().
